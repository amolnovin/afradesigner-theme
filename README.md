# قالب پرسونال برندینگ افرا حسین‌زاده (`afradesigner.ir`)

قالب مدرن، فوق‌سبک و واکنش‌گرای **برند شخصی افرا حسین‌زاده** (مدیر هنری، طراح جلد کتاب و متخصص صفحه‌آرایی) — ساخته‌شده با HTML5، CSS3 و JavaScript خالص بدون نیاز به فریم‌ورک یا ابزار باندلینگ.

## ویژگی‌های شاخص نسخه پرسونال برندینگ (v2.0)

- **سکشن اول (Hero) برند شخصی:** نمایش تصویر اصلی و بدون تغییر `assets/afra-hosseinzadeh.png` در قاب معماری آرک‌دار به همراه واترمارک تایپوگرافیک `AFRA HOSSEINZADEH`، نشانگر وضعیت پذیرش پروژه و آمار تعاملی.
- **نوار شناور پایین صفحه (Bottom Section Dock):** نوار شیشه‌ای (Glassmorphic) در پایین صفحه شامل آیکن‌های ۱۰ بخش اصلی سایت (`معرفی`، `اکوسیستم`، `درباره افرا`، `خدمات`، `نمونه‌کارها`، `فرآیند کار`، `رزرو مشاوره`، `نظرات`، `مجله` و `تماس`) با انیمیشن سینمایی جابه‌جایی بین سکشن‌ها و رصد خودکار اسکرول.
- **هدر مینیمال با کشوی همبرگری و جستجوی هوشمند در گوشه چپ:**
  - **آیکن جستجو (`Ctrl + K`):** جستجوی زنده و آنی در میان بخش‌ها، خدمات، نمونه‌کارها و مقالات با پشتیبانی کامل صفحه‌کلید.
  - **منوی همبرگری چپ‌بازشو:** دسترسی کامل به تمامی ۸ صفحه قالب به همراه کارت پروفایل و شبکه‌های اجتماعی.
  - **تم دوگانه (تاریک زمردی برندینگ / روشن کاغذی):** بدون پرش رنگ در بارگذاری اولیه (Zero-FOUC).
- **بخش اکوسیستم خدمات (Bento Hub):** چیدمان بنتو الهام‌گرفته از وب‌سایت‌های مدرن برند شخصی به همراه نوار متحرک تخصص‌ها.
- **ابزارهای تعاملی حوزه نشر:** ماشین‌حساب برآورد لحظه‌ای تعرفه صفحه‌آرایی و جلد، فرم ثبت سفارش ۴ مرحله‌ای با انتقال خودکار پارامترها، تقویم شمسی رزرو مشاوره و گالری نمونه‌کار با لایت‌باکس.

## ساختار فایل‌ها

```text
afradesigner-theme/
├── index.html                    صفحه اصلی پرسونال برندینگ (۱۰ سکشن کامل + دک پایین صفحه)
├── services.html                 خدمات تخصصی، بسته‌های قیمتی، ماشین‌حساب تعرفه و جدول مقایسه
├── portfolio.html                آرشیو نمونه‌کارها با فیلتر و لایت‌باکس
├── order.html                    فرم ثبت سفارش ۴ مرحله‌ای با برآورد لحظه‌ای هزینه
├── consult.html                  رزرو جلسه مشاوره رایگان ۲۰ دقیقه‌ای با تقویم شمسی
├── about.html                    بیوگرافی، مسیر حرفه‌ای و معرفی تیم افرا حسین‌زاده
├── blog.html                     مجله تخصصی طراحی کتاب و نشر با فیلتر دسته‌بندی
├── contact.html                  راه‌های ارتباطی و فرم تماس مستقیم
├── css/style.css                 سیستم طراحی CSS، تم تاریک/روشن، دک پایین، کشوی چپ و انیمیشن‌ها
├── js/main.js                    موتور انیمیشن سکشن‌ها، جستجوی زنده، فرم‌ها، فیلتر و لایت‌باکس
├── assets/
│   ├── afra-hosseinzadeh.png     تصویر اصلی پرتره افرا حسین‌زاده (RGBA PNG بدون تغییر)
│   └── *.jpg                     تصاویر نمونه جلد و صفحه‌آرایی
└── build.py                      اسکریپت پایتون تولید یکپارچه تمام صفحات HTML
```

## اجرا و پیش‌نمایش محلی

فایل `index.html` را مستقیم در مرورگر باز کنید یا یک وب‌سرور محلی اجرا نمایید:

```bash
python3 -m http.server 8080
```

## ویرایش و بازسازی صفحات

پس از تغییر محتوا یا اجزای مشترک در `build.py`، دستور زیر را اجرا کنید تا هر ۸ صفحه به‌روزرسانی شوند:

```bash
python3 build.py
```
