# قالب بازطراحی‌شده‌ی افرا گرافیک (afradesigner.ir)

قالب استاتیک، مدرن و واکنش‌گرا (HTML + CSS + JS خالص، بدون فریم‌ورک) برای استودیوی طراحی جلد و صفحه‌آرایی.

## ساختار

```
afradesigner/
├── index.html        صفحه اصلی (هیرو، خدمات، نمونه‌کار، فرآیند، درباره، نظرات، FAQ)
├── services.html     خدمات، بسته‌های قیمتی، ماشین‌حساب برآورد، جدول تعرفه
├── portfolio.html    گالری نمونه‌کار با فیلتر و لایت‌باکس
├── order.html        فرم ثبت سفارش ۴ مرحله‌ای با برآورد لحظه‌ای هزینه
├── consult.html      رزرو مشاوره رایگان (تقویم شمسی + انتخاب ساعت)
├── about.html        درباره افرا و تیم
├── blog.html         مجله / مقالات + خبرنامه
├── contact.html      تماس با ما
├── css/style.css     استایل کامل (متغیرهای CSS، حالت تاریک، RTL)
├── js/main.js        تعاملات (منو، تم، فیلتر، لایت‌باکس، فرم‌ها، اعتبارسنجی)
├── assets/           تصاویر نمونه (جایگزین با نمونه‌کارهای واقعی کنید)
└── build.py          اسکریپت تولید صفحات (هدر/فوتر مشترک)
```

## اجرا
فایل `index.html` را مستقیم باز کنید یا:
```bash
python3 -m http.server 8080
```

## ویرایش
- **محتوا/صفحات:** `build.py` را ویرایش و سپس `python3 build.py` را اجرا کنید تا هدر و فوتر همه‌ی صفحات یک‌جا به‌روز شوند. (می‌توانید HTMLها را مستقیم هم ویرایش کنید.)
- **رنگ‌ها و فونت:** بخش `:root` در `css/style.css`.
- **قیمت‌ها:** شیء `PRICES` در `js/main.js` (فرم سفارش) و ماشین‌حساب صفحه خدمات.
- **شماره تماس / واتساپ:** در `build.py` جست‌وجو کنید `0912 000 0000` و `989120000000`.

## اتصال فرم‌ها به سرور
فرم‌ها فعلاً نمایشی هستند (ارسال شبیه‌سازی‌شده). برای اتصال واقعی، در `js/main.js` بخش `orderForm.addEventListener("submit"...)` و `consultForm` را با `fetch()` به API خود، Formspree، یا افزونه‌ی فرم وردپرس (Gravity/WPForms REST) وصل کنید.

## تبدیل به قالب وردپرس
هر صفحه را می‌توان به‌سادگی به Template وردپرس یا بلوک‌های المنتور تبدیل کرد؛ CSS و JS مستقل هستند و فقط باید enqueue شوند.
